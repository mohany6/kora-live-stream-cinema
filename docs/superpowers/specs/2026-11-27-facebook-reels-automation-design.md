# تصميم نظام أتمتة فيديوهات Facebook Reels لصفحة كورة لايف

> **حجم العمل:** مشروع متكامل متوسط الحجم (إضافة مولّد صوت عربي + مشروع Remotion عمودي `1080×1920` + رافع Facebook Reels عبر Graph API + دمجه في الأتمتة اليومية وCI).

---

## 1. الهدف والسبب (Intent & Why)
تحويل بيانات المباريات والنتائج المتوفرة في المنصة تلقائياً إلى فيديوهات **Facebook Reels** عمودية عالية التفاعل تُنشر على صفحة **كورة لايف - Kora Live**، بهدف:
- الاستفادة من التوزيع القوي لخوارزمية Reels لغير المتابعين (**Unconnected Distribution**).
- تحويل المشاهدات إلى زيارات فعلية لمقالات **Blogger** بدون التعرّض لعقوبة خفض الوصول الناتجة عن وضع روابط داخل الوصف.

---

## 2. الأهداف، وما خارج النطاق، وما نمنعه (Goals, Non-Goals, Anti-Goals)

### الأهداف (Goals)
- إنتاج فيديوهات Reels أصلية 100% بمقاس **9:16 (`1080×1920`)**، بمعدل **30fps**، وصيغة **MP4 (`H.264` + `AAC`)** مطابقة لمواصفات `POST /{page_id}/video_reels`.
- مدة كل Reel بين **15 و22 ثانية** بإيقاع سريع وهوك جدلي في أول 3 ثوانٍ مع نهاية متصلة بالبداية (**Seamless Loop**) لرفع معدل الإكمال.
- توليد تعليق صوتي عربي حماسي تلقائياً لكل فيديو عبر `edge-tts` (صوت عربي واضح مثل `ar-EG-ShakirNeural` أو `ar-SA-HamedNeural`) متزامن مع مشاهد الفيديو.
- تغطية 3 أنواع محتوى تلقائياً:
  1. **Reel ما قبل المباراة** (يُنشر قبل انطلاق كل مباراة ترند بـ 30 دقيقة، بهاشتاجات المباراة الخاصة).
  2. **Reel ملخص النتيجة** (يُنشر بعد انتهاء المباراة).
  3. **Reel جدول/ترند اليوم** (ملخص سريع لأقوى مباريات اليوم).
- نشر الـ Reel بدون أي روابط في الـ Caption، وإضافة رابط المقال في **أول تعليق** تلقائياً عبر Graph API.
- منع التكرار عبر كاش محلي (`data/published_facebook_reels.json`) ودمج التشغيل في GitHub Actions كل 20 دقيقة.

### خارج النطاق (Non-Goals)
- النشر على TikTok أو YouTube Shorts أو Instagram في هذه المرحلة (التركيز على **Facebook Reels فقط**).
- سحب أو قص لقطات بث تلفزيوني حية.

### ما نمنعه (Anti-Goals)
- **لا روابط في وصف الـ Reel (`caption` / `description`)** إطلاقاً.
- **لا علامات مائية** (لا شعارات TikTok أو CapCut أو قنوات بث).
- **لا مقدمات بطيئة** (أول 3 ثوانٍ تبدأ فوراً بهوك بصري ونصي وصوتي).

---

## 3. القيود التقنية (Constraints)
- يجب أن يعمل التوليد والرفع آلياً بدون واجهة تفاعلية داخل بيئة Windows محلياً وUbuntu في GitHub Actions.
- الاعتماد على `FB_PAGE_ID` و`FB_PAGE_ACCESS_TOKEN` الموجودين حالياً في `.env` وGitHub Secrets.
- احترام مواصفات Meta Graph API لـ Reels:
  - `upload_phase=start` -> رفع الملف الثنائي إلى `rupload.facebook.com` -> `upload_phase=finish` (`video_state=PUBLISHED`) -> `POST /{post_id}/comments` للرابط في أول تعليق.

## 4. البدائل المدروسة والاختيار المعتمد (Approaches)

| الخيار | الفكرة | المميزات | المقايضات |
|---|---|---|---|
| **الخيار الأول (المختار): Remotion + Edge-TTS** | قوالب React Motion Graphics عمودية `1080×1920` تُرندر عبر Remotion (مع FFmpeg المدمج) + تعليق صوتي عربي `edge-tts` | حركة سينمائية سلسة، دعم كامل للـ RTL والعربية عبر Chromium، هوك بصري قوي يوقف التمرير | يضيف حزمة Node/Remotion صغيرة بجانب بايثون |
| **الخيار الثاني: HTML/Chrome PNGs + FFmpeg** | التقاط صور متتابعة ودمجها بـ FFmpeg | بايثون + FFmpeg فقط بدون Node | أنيميشن محدود وأبسط بكثير بصرياً في أول 3 ثوانٍ |

- **الاختيار المعتمد:** **الخيار الأول (Remotion + Edge-TTS)** بناءً على اختيار المستخدم، لأنه يعطي أعلى جودة بصرية قادرة على المنافسة في خوارزمية Facebook Reels.

## 5. معمارية الحل (Architecture & Pipeline)

1. **مولّد السيناريو والتعليق الصوتي (`src/live_score/domain/facebook_reel_script.py` + `edge-tts`):**
   - يبني سكريبت قصير (4 مشاهد / 15–20 ثانية):
     - **المشهد 1 (0–3ث — Hook):** سؤال جدلي أو تحدي توقعات + شعارَي الفريقين بحركة سريعة.
     - **المشهد 2 (3–9ث — Info):** التوقيت (القاهرة/مكة) والبطولة والقناة، أو النتيجة النهائية والأهداف.
     - **المشهد 3 (9–15ث — Hype/Engagement):** دعوة للتوقع/التعليق لرفع التعليقات والمشاركات.
     - **المشهد 4 (15–18ث — CTA + Loop):** *"رابط التشكيلة والتفاصيل في أول تعليق 👇"* مع انتقال سلس يعود للبداية.
   - يحوّل النص إلى ملف صوتي `MP3` عبر `edge-tts` ويقرأ مدته لضبط توقيت الفيديو.
2. **مشروع Remotion (`video_reels/`):**
   - قالب `MatchReel` عمودي `1080×1920` بهوية **Cyber-Stadium** (خلفية داكنة، إضاءة نيون خضراء/ذهبية، شعارات الأندية، نصوص عربية RTL بخط Cairo/Tajawal، وترجمة نصية متزامنة على الشاشة).
   - يستقبل `props.json` (بيانات المباراة + مسار الصوت + نوع الـ Reel) ويُخرج `MP4` جاهز للنشر.
3. **رافع Facebook Reels (`scripts/auto_facebook_reels_publisher.py` أو توسيع الناشر):**
   - ينفذ دورة الرفع الرسمية `/{page_id}/video_reels` (3 مراحل) ثم يضيف أول تعليق بالرابط، ويسجل المفتاح في `data/published_facebook_reels.json`.
   - يلتزم بنافذة **30 دقيقة قبل المباراة** في `--mode auto`.
4. **التكامل مع CI (`sync_and_publish.yml`):**
   - إعداد Node + Remotion + `edge-tts` في الـ workflow وتشغيل النشر التلقائي مع حفظ `data/published_facebook_reels.json`.

---

## 6. ما يُترك لمرحلة خطة التنفيذ (Left to the Builder)
- تقسيم المهام التفصيلي، تثبيت الحزم (`edge-tts` و`remotion`)، كتابة الاختبارات للسكريبت ورفع الـ API (مع Mocking في الاختبارات)، والتحقق من الرندر الفعلي لـ MP4 وتجربة النشر المباشر على الصفحة.
